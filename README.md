# AI Translator

單頁 Gemini 翻譯網站，支援使用者自帶 API KEY、模型切換、語言選擇、翻譯交換、複製與下載，並針對手機與桌機做了不同排版。

## 開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
```

## 功能

- 輸入 Gemini API KEY
- 選擇 Gemini 模型
- 輸入任意語言文字
- 選擇翻譯語言
- 呼叫 Gemini API 只回傳翻譯結果
- 顯示翻譯輸出
- 交換輸入與輸出
- 複製與下載翻譯內容
- 日文輸出加入漢字讀音標註
- 桌機左右排版，手機上下排版
